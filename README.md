# 🧑‍💼 Employee Management System (EMS)

A full-stack **Employee Management System** built to replace manual HR record-keeping.

This application allows HR teams to manage employee data, track attendance, and generate reports in Excel/PDF formats.

---

## 🚀 Project Overview

The system provides a digital HR solution with:

- Secure login authentication  
- Employee CRUD operations  
- Attendance tracking  
- Report generation for employees and attendance  

Built as part of a company assignment using modern full-stack technologies.

---

## ✅ Key Features

### 🔐 Authentication & Security
- JWT-based login system
- Protected access to HR modules

---

### 👨‍💼 Employee Management
- Add new employees  
- Edit employee details  
- Delete employee records  
- View employee directory  

---

### 📅 Attendance Module
- Mark attendance as Present/Absent  
- View attendance history  

---

### 📊 Reports Module
- Export Employee Directory to Excel  
- Export Attendance Report to Excel  
- Export Employee Report as PDF  

---

### 🧭 Dashboard & Navigation
- Dashboard landing page after login  
- Navbar navigation across modules  
- Quick access cards for Employees, Attendance, Reports  

---

## 🛠 Tech Stack

### Frontend
- React.js + TypeScript  
- Axios  
- React Router DOM  

### Backend
- ASP.NET Core Web API  
- Clean Architecture  
- Repository + Service Pattern  

### Database
- MySQL  

### Reporting Tools
- ClosedXML (Excel Export)  
- QuestPDF (PDF Export)
